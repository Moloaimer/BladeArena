# 美术来源与生成提示词

本项目的五份 PNG 使用内置 image_gen 生成，没有从素材网站下载。角色为用户指定的 Fate 同人表现，不是官方素材或官方授权证明。角色采用单张立绘 Sprite，移动使用代码翻转、摆动及受击闪烁，不包含逐帧行走图集。石砖地面提示词另见 COURTYARD-PROMPT.md。

## artoria

Use case: stylized-concept. Asset type: transparent Unity 2D game character sprite. Create ONE full-body pixel art chibi Artoria Pendragon (Saber from Fate), recognizable blonde braided bun with ahoge, green eyes, blue dress with white skirt panels, silver breastplate and armored boots, blue ribbons. Empty hands at sides, no sword (weapons orbit separately). Front facing slight top-down RPG perspective. True crisp 16-bit pixel art, restrained palette, clear dark pixel outline, compact three-head-tall proportions, no smooth painterly shading. Single centered character filling 80% image height, full feet visible, generous transparent margins on all sides. Genuine transparent alpha background, no ground, no text, no frame, no watermark, no other objects. Suitable as in-game sprite, not a portrait.
