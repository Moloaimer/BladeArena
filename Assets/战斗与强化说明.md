# 战斗与强化：统一规则

本页描述当前实际实现。入口仍是 `Scenes/BladeArena.unity`，Prefab、强化资源和数值可在 Inspector 编辑。

统一命名，围绕玩家旋转的称为剑，剑容量上限设置为剑阵容量，敌人的可以沿用敌刀这个称呼
每次剑旋转攻击敌人造成伤害称为直接伤害，其余为技能伤害，之后的机制沿用这套称呼
## 无上限指什么

- 玩家初始生命 100、剑攻击力 10、基础持剑数 3、剑阵容量 30。
- 剑阵扩充每级容量 +5，容量为 `30 + 5 × 等级`，无上限
- 所有 **26 项强化**均可反复选择，没有最高等级。稀有、进化也有后续成长效果。
- 当前刀数仍不能超过已经获得的容量。拾球、重铸和奖励遵守同一容量；这是资源管理规则，不是最终成长封顶。
- 等级无上限不代表取消碰撞去重、概率范围、技能冷却或进化前置。
- 普通 / 稀有 / 特殊 抽取权重为 75 / 20 / 5。只从当前可选的档位中抽取，每次最多三个不同选项；已获得选项不会因等级高而退出池。

## 暴击的唯一口径

基础暴击率 **0%**，基础暴击伤害 **200%**。200% 表示一次暴击造成普通命中的 2 倍伤害，不是额外再增加 200%。

暴击剑术每级增加 **10 个百分点**总暴击率。总暴击率超过 100% 的部分，按用户确认的 **1:1** 转为暴击伤害百分点。不另设独立的“双倍伤害概率”或重复叠加的暴伤升级。

| 暴击剑术等级 | 总暴击率 | 实际暴击率 | 暴击伤害倍率 |
| ---: | ---: | ---: | ---: |
| 0 | 0% | 0% | 200% |
| 1 | 10% | 10% | 200% |
| 10 | 100% | 100% | 200% |
| 13 | 130% | 100% | 230% |
| 20 | 200% | 100% | 300% |

```
实际暴击率 = min(总暴击率, 100%)
暴击伤害 = 200% + max(总暴击率 - 100%, 0)
```

例如，普通命中伤害为 10，总暴击率 130% 时每次必定暴击，最终造成 23 伤害。溢出由当前属性重新计算，刷新属性不会重复追加暴伤。

所有的伤害共用这套暴击规则，单独计算。每个目标每次伤害单独判断暴击；衍生攻击不再触发剑气计数、圣剑蓄能或新的爆发。

## 碰撞规则

- 玩家剑命中敌人身体：造成伤害，玩家剑保留。
- 剑碰刀：双方立即移出判定并隐藏、销毁。王之财宝飞剑也属于可被拦截的敌刀。
- 敌刀命中玩家：造成伤害，敌刀不消耗；玩家无敌或用护盾抵挡时，敌刀消失。
- 同剑对同目标持续重叠只结算一次；离开再接触才产生新的命中。不同剑可各自命中。
- 先结算剑碰刀，再结算身体命中；Boss 补刀也在本轮碰撞前完成。
- 玩家受伤后无敌 0.8 秒。敌人不使用全身受击无敌屏蔽不同刀的命中。
- 身体碰身体不掉血。判定采用圆形半径；剑刃塑形同步改变外观与实际判定。

## 普通强化：14 项

`L` 表示对应强化的当前等级并非角色总等级。伤害、生命、容量按基础值线性累加；转速、半径、尺寸、击退距离按平方根递减成长，没有等级封顶。

| 强化 | 统一效果 |
| --- | --- |
| 剑阵扩充 | 持刀上限 +5
| 锋刃强化 | 攻击 +20% × √L
| 高速轮转 | 基础转速加成 +12% × √L
| 扩大阵型 | 基础环绕半径加成 +10% × √L
| 身法 | 基础移动速度加成 +10% × √L
| 剑刃塑形 | 外观与判定尺寸加成 +10% × √L；由原宽刃和剑身延伸合并
| 剑气生成 | 首级生成率 20%，每次直接伤害时判定，生成一道黄色剑气（不占用容量），向最近的敌人造成单次当前攻击力百分百的伤害（不穿透，不暴击，不计入破碎重铸等任何计数，只单次攻击）
| 骑士体魄 | 基础最大生命 +10% × L；每次选择恢复新上限的 20% |
| 破甲 | 对精英 / Boss 的全伤害 +15% × √L |
| 暴击剑术 | 总暴击率 +10 个百分点 × L；溢出 1:1 转暴伤 |
| 魔力回收 | 每把被撞碎的玩家剑回收 10 × L 能量；每 100 能量换一层护盾；护盾容量 +L |
| 快速重铸 | 首级 15% 概率在剑碎裂 3 秒后返还一把剑，概率随等级递增、收益递减 |
| 完美格挡 | 首级 0.2 秒无敌，后续递减延长并趋近 0.35 秒；每 0.6 秒最多触发一次 |
| 残刃冲击 | 碎剑位置 2.5 米内击退敌人，距离为 0.6 × √L 米 |

空间属性递减成长示例：剑刃塑形 1 级 +10%，4 级 +20%，100 级 +100%。没有暗中把等级卡在某一级。模拟步长会随刀尖速度和碰撞尺寸调整；补刀也不再逐把排序整个刀阵。

### 剑气生成溢出

将生成率拆成整数部分和小数部分：整数部分为每颗球必得的额外刀数，小数部分为再多一把的概率。

- 20%：20% 概率生成剑气
- 155%：必生成一道剑气，另有 55% 概率再生成一剑气。
- 200%：必生成两道剑气


## 稀有与进化：12 项

### 稀有
    
- **双层剑阵**：首次解锁反向双圈；同时提供 `5% × √L` 的基础转速加成。双圈半径为环绕半径的 72% / 115%。
- **三重剑阵**：首次需要双层剑阵且当前至少 30 把刀。解锁后保持三圈，不再因碎刀反复切换；重复升级不再检查 30 把条件。每级提供 `5% × √L` 的基础环绕半径加成。三圈半径为 65% / 97.5% / 130%。（上限大于30且刀数量大于30时填充最外层）
- **圆桌集结**：每完整的 10 把当前飞刀，刀伤害增加 `5% × L`。
只有剑阵扩充不会自动变成多圈。内圈的优先权限于确实接触到敌刀的情况，不是远程吸收或保证挡住所有攻击。

- **贯穿剑气**：每 8 次伤害（只计算飞刀），发射一道贯穿剑气；伤害为 `基础刀伤害 B × L`。
- **聚能斩击**：同一目标被不同刀连续命中增加层数，最多 5 层，每层增加 `10%× L` 伤害。相同刀再次命中不加层、也不清空已有层数；1.5 秒未命中该目标才清空。
- **碎刃爆发**：玩家刀被撞碎，在碎刀处 2 米范围造成 `B × 150% × L` 伤害。
剑气和圣剑对同一个目标只命中一次，可以贯穿多个敌人；目前使用保存的 SwordWave Prefab 表现。

- **湖之加护**：每累计撞碎 10 把敌刀获得一层护盾，阈值固定；每级护盾容量 +1。重复升级保留已有计数，不会把需求变成 20 / 30 / 40 把。
- **魔力重铸**：仅当该次碎刀没有触发快速重铸时，增加重铸进度；首级每把 +20%，进度满 100% 返还一把，剩余进度保留。后续等级增加单次进度，收益递减。
- **反射剑芒**：格挡也有几率生成剑气，但与普通强化中的“剑气生成”分开判定，基础生成率10%，每级加5%

特殊：（只可选一次）
- **蓄魔**，获得三个魔力槽位，随时间回复，回复速度为每秒百分之1（即100s一个魔力），击杀敌人回复百分之五，获得主动技能E，E消耗一个魔力，补满所有的刀

拥有蓄魔之后才会抽出以下的特殊强化
- **圆桌剑阵**：解锁技能Q，消耗两个魔力，让围绕自己旋转的飞到组成剑阵，围绕自己扩大范围（可以和双层，三重的强化叠加范围）并加快攻速（不再规律转动而是像比较凌乱的那种感觉，但依旧围绕周身），且此时飞刀不会被摧毁，首级持续20s，每级延续2s
- **Excalibur**：解锁技能R， 消耗三个魔力，在黄色光效中蓄力1s，蓄力过程中飞刀消失，不可移动，但推开周围的敌人并霸体（会被王之宝库击中并扣血），然后对全屏进行一次倍率为百分之1000伤害的攻击，每级加百分之200倍率
- **Avalon**：解锁被动技能，抵挡致命伤时消耗当前持刀数的 20%，向上取整且至少消耗 5 把。保留 1 生命并无敌 2 秒；首级冷却 60 秒，后续递减缩短。刀不足或冷却中不能触发。

重铸的统一规则：**每把被撞碎的刀，两个机制合起来最多返还一把**。优先判断快速重铸，未触发时才存入魔力重铸进度。返还仍遵守当前容量，不是拾球，不触发双生。

快速重铸概率和魔力重铸进度都使用 `p × L / (1 - p + p × L)`，其中首级 p 分别为 0.15 / 0.20。有限等级下趋近但不超过 100%，不会因重复强化出现负向收益或一碎多返。

护盾容量为 `3 + 湖之加护等级 + 魔力回收等级`。每层挡一次伤害，护盾先于 Avalon 判定；护盾满时不额外储存整层，能量的小数余量保留。一次得到足够多的能量会正确换取多层护盾。

完美格挡无敌时间为 `0.2 + 0.15 × (L-1)/(L+4)` 秒，触发间隔固定 0.6 秒。Avalon 冷却为 `3 + 57/(1 + 0.15 × (L-1))` 秒，始终长于 2 秒无敌；升级影响下一次触发所用的冷却。献祭不算被敌刀撞碎，不触发回收、重铸、反射或爆发。

## 伤害与无尽难度

```
B = 攻击力
D（直接伤害）= B 
R = 1 + floor(当前刀数 / 10) × 0.05 × 圆桌集结等级
A = 1 + 0.15 × 破甲等级（仅精英 / Boss）
C = 1 + 0.10 × 连击层数 × 聚能斩击等级
T = 1 + 0.20 × 圆桌进化等级（仅外圈）
单刀普通命中 = B × R × A × C × T + 2 × 魔力附着等级
单刀暴击 = 单刀普通命中 × 当前暴击伤害倍率
```

未获得对应强化时，该乘区为 1。追加魔法不单独再掷一次暴击。剑气、反射、爆发、圣剑按各自的 B 倍率计算并独立判断暴击，不重复套用破甲、集结、连击或魔力附着。结算最后才取整；Unity 的 .5 使用就近偶数舍入。

角色 Prefab 基础生命：玩家 100、普通敌人 30、精英 150、Boss 1200；所有基础刀伤害为 10。新出生敌人生命乘以 `1 + 0.25 × 已经过分钟数`，伤害乘以 `1 + 0.10 × 已经过分钟数`。首个 Boss 约在 60 秒出现时为 1500 生命、11 伤害；后续每次已击败 Boss 再增加 400 生命。开场已摆放敌人沿用开局数值。

## 本次清理的不合理之处

| 原问题 | 当前处理 |
| --- | --- |
| 无尽模式的等级 / 50 把最终上限 | 取消最终容量封顶和所有强化等级上限 |
| 双倍伤害与暴击叫法混用 | 统一为暴击率、暴击伤害、超额转换 |
| 概率超过 100% 后升级浪费 | 暴击溢出转暴伤，双生溢出转保底数量 |
| 宽刃与延伸效果相同，8% 被 10% 完全压制 | 合并为剑刃塑形，强化池为 26 项 |
| 稀有 / 进化重复选择没有效果 | 增加明确的数值成长，保留首次机制解锁 |
| 湖之加护和魔力重铸重复升级会增加触发需求 | 固定湖之加护阈值；重铸改为递增进度 |
| 两种重铸叠加可一碎多返 | 共用每把碎刀一次返还预算 |
| 碎刀让三圈频繁切回双圈 | 首次解锁后保持三圈 |
| 圆桌进化使内圈失去输出 | 保留内圈攻击，新增外圈伤害成长 |
| 相同刀命中清空连击，速度升级可能负收益 | 相同刀只续时，不加层、不清空 |
| 无限叠无敌或固定五刀抵挡导致近似不死 | 格挡触发间隔；Avalon 比例消耗和独立冷却 |
| 玩家持续成长，普通敌人伤害永久固定 | 新敌人生命 / 伤害随时间成长 |

## 修改位置

- `Settings/Upgrades`：26 项强化名字、文案、稀有度、数值和首次前置条件，无 Max Level 字段。
- `Settings/DefaultArena.asset`：初始容量、暴击默认值与溢出比例、抽取权重、技能节奏、敌人成长等。
- `Gameplay/BladeProgression.cs`：等级、成长曲线、暴击计算、动态预告。
- `Gameplay/BladeCombat.cs`：命中、暴击应用、技能与防御。
- `Prefabs/Characters`：基础生命、伤害、移动、刀阵。

资源中的 Description 是可编辑文案；修改数值或阈值后须同步文案。暴击、容量和双生卡片的“下级”预告由实际配置自动计算。当前是已验证机制的初版平衡，未宣称完成长时间人工平衡试玩。
